# Legacy app (reference only)

The original vanilla HTML/JS version of F1 Kick Tip, kept for reference during the rebuild.

- `js/scoring.js` is the reference the new scoring module is tested against (`tests/parity.test.ts`).
- `data/season.json` is the source for the 2026 calendar, teams, drivers and players.
- `data/test/` holds the old demo fixtures.
- `js/api.js` is a stub: the original database client was removed, so these pages no longer load data.
